3Outcome, scope, exclusions, and Definition of Done

Planned outcome

A provider-neutral, API-first simulated exchange for battery flexibility, driven by live ERCOT Public API data, that completes the demo story of gridmarket-intent.html section 20 without crashing; entered in Open Grid Data and Most Commercializable.

Scope

  • Contract-first skeleton: S01 freezes every shared name as stubs plus CONTRACTS.md; owner's Worker security fix S24-S25 (the owner deploys).
  • Phase 1a walking skeleton (S02-S09): market, data, SDK, Overview page; assembly S09, PROC-ACCEPT-P1A.
  • Phase 1b rich core (S26-S33, S50-S51, spec S19-S21): bots, economy, router, views, pages; assembly S49, PROC-ACCEPT-P1, slip trigger for diversity.
  • Phase 2 (S10-S11, S34-S37): LoneStar adapter plus health, Providers page, strategy kit; assembly S12, PROC-ACCEPT-P2.
  • Stretch merged only when green (S13-S18, S22-S23, S38-S43): adversary kill switch, backtest, Rust core, ML, gridmarket-mcp, qlib, Jev; assembly S18 with drop records.
  • Final wave (S44-S48): user guide, llms.txt, onboarding skill, README Contributors, quick website onboarding; assembly S46.
  • Per-phase assurance (one review, one assurance pass, max one repair, deterministic verification, no re-review) and per-phase landing PRs to main.

Exclusions

  • Intent section 21: real settlement, billing, money, KYC/AML, QSE, blockchain, options, leverage, sophisticated margin.
  • Intent section 18 P2 except item 26 (ML stretch) and item 25 in limited form (user-brought agents via the prompt kit and local gridmarket-mcp): Google OAuth, personal bot, first-party AI trading agent, WebSockets, backtesting dashboard, sophisticated clearing.
  • Remote MCP server; bot evolution (layer 5b); retiring bots; judges spawning bots; Loki or another log stack.
  • TypeScript trading example and TypeScript SDK (DEC-GM-013).
  • Wind/solar forecast signals, renewable-deficit factor, special-events feed, TxDOT traffic, NWS alert history as an ML feature; porting the private weather fetcher.
  • Record-and-replay or replay-only data in the live data path (DEC-GM-007).
  • Agent edits under ercot-hackathon/ outside S24-S27; ERCOT credentials in the market; Worker deploy and secrets, Jev key and flag (owner-only); Jev disclosed in the video.
  • Owner actions: public flip plus ruleset, tunnel credentials, ERCOT account registration, GitHub link plus description plus 3-5 minute Loom video, team size at most 5.
