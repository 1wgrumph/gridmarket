3Outcome, scope, exclusions, and Definition of Done

Planned outcome

A provider-neutral, API-first simulated exchange for battery flexibility, driven by live ERCOT Public API data, that completes the demo story of gridmarket-intent.html section 20 without crashing; entered in Open Grid Data and Most Commercializable.

Scope

  • Phase 1 core: live ERCOT data via Jordan's Worker, NWS weather, seven-factor explainable score, matching engine with never-cut risk controls, SDK plus bots, Astryx dashboard (S01-S09).
  • ERCOT Worker security fix as first-wave agent slices S24-S25 on branch gridmarket/lane-worker with a PR into jordaaan; Jordan deploys (DEC-GM-022).
  • Phase 2: LoneStar Storage second provider adapter on the same books (S10-S12).
  • Stretch lanes merged only when green: adversarial scenario with kill switch, score backtest, Rust PyO3 core with benchmark, ML model comparison (S13-S18, S22-S23).
  • Spec lane: azdiagram generator, spec_build/spec_lint, spec skills, and GridMarket's own specification for the judges (S19-S21).
  • Ordered assembly with post-step V&V on gridmarket/integration, phase checkpoints, owner-run acceptance, and Lifecycle assurance.

Exclusions

  • Intent section 21: real settlement, billing, money, KYC/AML, QSE, blockchain, options, leverage, sophisticated margin.
  • Intent section 18 P2 items except item 26 (ML stretch): Google OAuth, personal bot, AI trading agent, WebSockets, backtesting dashboard, sophisticated clearing.
  • TypeScript trading example and TypeScript SDK (DEC-GM-013).
  • Wind/solar forecast signals, renewable-deficit factor, special-events feed, TxDOT traffic, NWS alert history as an ML feature.
  • Record-and-replay or replay-only data in the live data path (DEC-GM-007).
  • Agent edits under ercot-hackathon/ outside S24-S25; Worker deployment and secrets (Jordan); ERCOT credentials in the market.
  • Owner actions: tunnel credentials and tunnel up, public flip plus ruleset, ERCOT account registration, GitHub link plus description plus 3-5 minute Loom video, team size at most 5.
