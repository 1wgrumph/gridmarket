### 4.2 Feature Interfaces

**BLUF:** Features meet only at frozen, typed interfaces: Python protocols inside the process and the REST and Worker contracts outside it.

**Frame**

- **Who:** Lane implementers.
- **What:** Internal protocols, external interfaces, and the contract index.
- **Why:** API contract lens: all clients use one documented surface.
- **How:** Types in `contracts.py`; names indexed in `CONTRACTS.md`.
- **When:** Frozen at wave 1.
- **Where:** `backend/gridmarket_server/contracts.py` and `CONTRACTS.md`.

Section 4.2.1 lists the in-process interfaces, 4.2.2 the interfaces that cross
the system boundary, and 4.2.3 the rules that keep both stable.
