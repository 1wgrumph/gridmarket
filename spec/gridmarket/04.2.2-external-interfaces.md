#### 4.2.2 External Interfaces

**BLUF:** Two HTTP interfaces cross the boundary: the market's REST API for every client, and the ERCOT Worker's keyed, allowlisted, budgeted proxy for ERCOT data.

**Frame**

- **Who:** Every client of the market; the market as client of the Worker.
- **What:** CONTRACT-GM-API and CONTRACT-GM-WORKER, including the Worker security fix (DES-GM-EDGE).
- **Why:** One documented surface per boundary, with abuse controls at the edge.
- **How:** JSON over HTTPS with typed errors; the Worker enforces allowlist, key, per-client limit, and upstream budget.
- **When:** On every request.
- **Where:** Market behind the tunnel; Worker on the owner's Cloudflare account.

The market serves public reads without a key under an address rate limit,
`POST /v1/sandbox/keys`, keyed account and order routes, admin routes, and
`/openapi.json`. Errors are `{"error": {"code", "message"}}` with codes such as
`UNAUTHENTICATED`, `RATE_LIMITED`, `IDEMPOTENCY_CONFLICT`, `MARKET_HALTED`,
`ORDER_TOO_LARGE`, `POSITION_LIMIT`, `INSUFFICIENT_FUNDS`,
`INSUFFICIENT_CAPACITY`, `PROVIDER_OFFLINE`, `SANDBOX_CAP`, and `BOT_CAP`.
Only GETs of the six market and prediction reads and `/v1/router` from the
origin in `GRIDMARKET_CORS_ORIGIN` receive `Access-Control-Allow-Origin`;
account, trading, sandbox, and admin routes never do (AC-GM-API-05).

The Worker returns 404 without calling ERCOT for a report path outside the
five-path allowlist, and 401 for `/api/report/*`, `/api/products`, or
`/api/snapshot?fresh` without the market client key (AC-GM-EDGE-01). A
per-address limit of 30 requests per 60 s returns 429 before any ERCOT call
(AC-GM-EDGE-02). One guard in the shared ERCOT fetch path takes a unit from a
25-per-60-s budget before every ERCOT call, token requests and retries
included, and answers from cache or 429 when it is empty (AC-GM-EDGE-03). On
ERCOT 429 while building the snapshot it retries at most 4 times, waiting
min(4 s, `Retry-After`) or min(4 s, 0.9 s × attempt) (AC-GM-EDGE-04).

Table (T2): External interface groups

| Interface | Producer | Consumer | Payload |
|---|---|---|---|
| Public reads `/v1/market*`, `/v1/predictions*`, `/v1/signals`, `/v1/providers*`, `/v1/router`, `/v1/bots*` | Market | Dashboard, SDK, views, agents | JSON, IP rate limit |
| Keyed routes `/v1/account`, `/v1/portfolio`, `/v1/positions`, `/v1/trades`, `/v1/losses`, `/v1/assets*`, `/v1/orders*` | Market | Key holders | JSON, Bearer key, Idempotency-Key on orders |
| Admin routes `/v1/admin/*` | Market | Owner on loopback | JSON, admin key |
| `/api/snapshot`, `/api/report/<emil-id>/<report>` | ERCOT Worker | Market | Snapshot JSON; ERCOT `{fields, data, _meta}` |
| `/v1/market/activity`, `/v1/router` by CORS GET | Market | Worker views | JSON |
