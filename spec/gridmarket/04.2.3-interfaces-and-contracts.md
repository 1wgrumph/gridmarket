#### Interfaces and contracts

**BLUF:** Every shared name lives in `CONTRACTS.md` from wave 1, and changing one is a recorded amendment, never a lane's local edit.

**Frame**

- **Who:** Every lane, the S01 route, and the Integration Engineer.
- **What:** The contract index and its amendment procedure (CONTRACT-GM-INDEX).
- **Why:** Parallel lanes diverge silently when a shared name is not frozen (RISK-GM-19).
- **How:** Contract tests run on every lane; frozen files change only on `gridmarket/contract-<n>`.
- **When:** Frozen before any wave 2 slice; amended by dated entries.
- **Where:** `CONTRACTS.md`, `contracts.py`, `schema.sql`, `main.py`, `api.ts`, `App.tsx`, and `hooks.ts`.

The wave 1 exit commit contains `CONTRACTS.md` and stubs naming every shared
module, type, route, field, header (`Authorization`, `Idempotency-Key`,
`X-RateLimit-Limit`, `X-RateLimit-Remaining`, `Retry-After`,
`x-gridmarket-key`), ledger and event entry type, bot and router field, MCP
tool, Worker snapshot field, and dashboard route and hook, and the contract
tests pass against the stubs (AC-GM-CONTRACT-01). An amendment appends a
dated entry with name, old, new, reason, and affected lanes; every affected
lane merges it before its exit, and the Integration Engineer merges it first
in the next assembly.
