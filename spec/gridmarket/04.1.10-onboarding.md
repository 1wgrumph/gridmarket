#### 4.1.10 SDK, strategy template, prompt kit, and gridmarket-mcp

**BLUF:** Every way to trade GridMarket, from a 30-line script to a user's own LLM agent, is a thin client of the public API under the same risk engine and limits.

**Frame**

- **Who:** Judges, developers, and users' LLM agents.
- **What:** The SDK, strategy template, prompt kit, gridmarket-mcp, and user guide (DES-GM-SDK, DES-GM-KIT, DES-GM-MCP, DES-GM-DOCS).
- **Why:** Onboarding lens: from zero to a live order quickly and safely.
- **How:** A stdlib `urllib` SDK with a fresh `uuid4` Idempotency-Key per order, and documents served by the app.
- **When:** SDK in phase 1a, kit in phase 2, MCP in stretch, guide in the final wave.
- **Where:** `sdk/python/`, `examples/`, `docs/llm/`, `mcp-server/`, and `docs/USER_GUIDE.md`.

The SDK `Client` wraps the public API for market data, predictions, the
caller's account and orders, order placement with a fresh Idempotency-Key,
and cancellation (DES-GM-SDK). The
strategy template uses only the standard library and the SDK, reads
predictions, and clamps size to 50 and the position to 200 before sending
(AC-GM-KIT-01). `docs/llm/system-prompt.md` states that trading is simulated,
the 50-credit order limit, and the 200-credit position limit, includes the
`/openapi.json` URL and an SDK snippet, and a test checks its numbers against
the risk engine's constants (AC-GM-KIT-02).

gridmarket-mcp runs on the user's machine over stdio with the user's own key,
exposes read tools and caller-scoped tools, places orders only through the
public API, and returns numbers, ids, and enums only, never another user's
free text (AC-GM-MCP-01). It depends on an `mcp` release public for at least
14 days, and no remote MCP server is deployed (AC-GM-MCP-02). The user guide
and `llms.txt` give numbered steps for each landed capability and every
landed error code, and describe nothing that has not landed (AC-GM-DOC-01).
