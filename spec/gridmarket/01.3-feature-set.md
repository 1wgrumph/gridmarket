### 1.3 Feature Set

**BLUF:** GridMarket ships in declared phases, each demonstrable on its own, so a late stretch lane never blocks a working market.

**Frame**

- **Who:** The owner who records the demo and the judges who watch it.
- **What:** The feature set per delivery phase and its acceptance run.
- **Why:** Phased delivery keeps `main` demoable after every landing (DEC-GM-005, DEC-GM-038).
- **How:** Each phase is assembled, reviewed once, repaired at most once, and landed through a merged PR.
- **When:** Phase targets Sat 10:00 (1a), Sat 16:00 (1b), Sat 19:00 (2) CDT; feature freeze Sun 07:00 CDT.
- **Where:** Integration branches `gridmarket/integration-<phase>` merged to `main`.

Phase 1a is the walking skeleton and phase 1b the rich core; together they
are the core the demo depends on. Phase 2 adds the second provider and the
health checks. Stretch lanes run in parallel and merge only when green. The
spec lane is part of phase 1b but never blocks its landing. Each phase closes
with one uninterrupted acceptance run against its integrated candidate: the
phase 1a run shows SC-1, SC-3, SC-4, SC-5, SC-7, SC-8, and SC-10
(AC-GM-ACC-03); the phase 1b run shows SC-1 to SC-5 and SC-7 to SC-11
(AC-GM-ACC-01); the phase 2 run shows SC-1 through SC-11 and the simulated
LoneStar Storage outage (AC-GM-ACC-02).
