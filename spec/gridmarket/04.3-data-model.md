### 4.3 Data Model

**BLUF:** One SQLite schema, frozen in wave 1, is the only state; append-only triggers protect the ledger, and everything else can be rebuilt from it.

**Frame**

- **Who:** Every module that reads or writes state.
- **What:** The tables of CONTRACT-GM-SCHEMA and their roles.
- **Why:** A single system of record makes restart and audit trivial.
- **How:** SQLite in WAL mode on a named Docker volume; `BEGIN IMMEDIATE` for every state change.
- **When:** Created at first start; frozen at wave 1.
- **Where:** `backend/gridmarket_server/schema.sql` and the `gm-data` volume.

Triggers `RAISE(ABORT)` on UPDATE or DELETE of `trades`, `events`,
`deposits`, and `settled_positions`. API keys are stored only as SHA-256
hashes. A schema change after wave 1 is a planning delta.

Table (T5): Data dictionary

| Field | Type | Unit | Meaning |
|---|---|---|---|
| `accounts` | table | — | Humans, sandbox accounts, and bots with cash |
| `api_keys` | table | SHA-256 hex | Key hashes, labels, sandbox flag |
| `providers`, `assets` | tables | kWh, kW | Provider companies and batteries with SoC, reserve, limits |
| `products` | table | delivery hour | Spot and future products per zone |
| `orders`, `trades` | tables | credits, $/credit | Orders and append-only fills |
| `positions`, `reservations` | tables | credits, kWh | Signed holdings and capacity holds per hour |
| `idempotency` | table | — | Stored response per account and Idempotency-Key |
| `events`, `anomalies`, `halts` | tables | — | Append-only settlements, halts, lifts, alerts; detected anomalies |
| `signals` | table | report unit | ERCOT and NWS values with interval, publish, and fetch time |
| `settlements`, `settled_positions` | tables | $ | Expiry reference prices and realized P&L per holding |
| `deposits` | table | $ | Append-only payroll entries |
| `bots`, `bot_meta` | tables | — | Bot specs and the stored master seed |
| `router_results` | table | probability | Check results, bands, outcomes, Jev column |
| `provider_health` | table | s | Heartbeats and online state |
| `sandbox_issuance` | table | — | Sandbox keys per client address and time |
