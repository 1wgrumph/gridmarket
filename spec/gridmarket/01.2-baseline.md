### 1.2 Baseline

**BLUF:** The baseline of this specification is the approved planning package of Lifecycle GM-2026-09-25 and the contract-first skeleton that freezes every shared name.

**Frame**

- **Who:** Implementers, reviewers, and the Integration Engineer.
- **What:** The documents and commits this specification is written against.
- **Why:** So that a reader can tell which decisions and names this text assumes.
- **How:** Cite design and contract identifiers; change a shared name only by a recorded amendment in `CONTRACTS.md`.
- **When:** From the plan approval (DEC-GM-044) through the final wave.
- **Where:** The Lifecycle plan directory and the repository `main` branch.

The design baseline is `design.md` and the technical baseline is
`gridmarket-technical-plan.md` in the Lifecycle plan directory
`docs/plans/2026-09-25-gridmarket/`. The code baseline is the wave 1 exit
commit of slice S01, which writes `CONTRACTS.md` (CONTRACT-GM-INDEX) and
code stubs for every shared module, type, route, field, header, ledger entry
type, bot and router field, MCP tool, Worker snapshot field, and dashboard
route and hook (DEC-GM-039).
